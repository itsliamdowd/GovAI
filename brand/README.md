# GovAI logo

- `govai-icon.svg` + `govai-icon-{32..1024}.png`: app icon (civic building + spark on a dark rounded square). Use for app stores, favicons, social avatars.
- `govai-mark-white.svg` + `govai-mark-white-512.png`: the mark alone, white strokes, transparent background, for dark surfaces.
- `govai-mark-dark.svg` + `govai-mark-dark-512.png`: the mark alone, near-black strokes, transparent background, for light surfaces.
- `govai-lockup-dark.svg`, `govai-lockup-light.svg` + `*-1600x480.png`: mark + "GovAI" wordmark (Georgia 600), 400x120 artboard, PNG at 4x.
- `favicon.ico`: 16, 32, 48 and 64 px.

Colors: background #0b0e13, ink #e8eaed, spark #fbbf24 (dark) / #f59e0b (light). Mark stroke 1.5 on a 24-unit grid; keep clear space of at least one grid unit.
