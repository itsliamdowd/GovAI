## Home Occupation Permit (Home-Based Businesses)

The Santa Ana Municipal Code requires that every business operating from residential premises secure a Home Occupation Permit (HOP) and comply with all applicable provisions of the City's Municipal Code relating to home-based businesses/home occupations. The City Council approved reducing the HOP fee from $320 to $50.32.

Home-based businesses must apply for and receive an approved HOP before they apply for a Santa Ana Business License. To fill out an application and get more information about Home Occupation permits, visit https://santa-ana.gov/certificate-of-occupancy-home-occupation-permit/.

Source: https://santa-ana.gov/santa-ana-lowers-fee-for-home-based-business-permits/

## Building Permit Applications — 2022 California Building Standards Code

The State updates the California Code of Regulations (Title 24) every three years. The new 2022 California Building Standards Code goes into effect on January 1, 2023. All construction project applications submitted on or after that date must comply with the provisions of the new codes.

If a project is designed under 2019 codes, the City strongly encourages submitting the permit application on or before December 15, 2022 to allow adequate time to process the application.

Source: https://santa-ana.gov/new-2022-california-building-standards-code/

## Residential Permit Parking Program

The Public Works Agency is revamping the Residential Permit Parking Program and is seeking input, comments, and suggestions. To set up a meeting for a presentation to your neighborhood or for more information, contact (714) 647-5623 or permitparking@santa-ana.org.

Learn more about the program at santa-ana.gov/permit-parking.
